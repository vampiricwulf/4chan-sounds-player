4chan Sounds Player

A floating music player for 4chan sounds threads. It finds every [sound=…] image in a thread, builds a playlist, and plays the image or webm with its audio.

Install v{{VERSION}} Installation guide Settings reference
Thread playlistEvery sound in the thread, in order, with drag to reorder, search, shuffle and repeat.
Inline playbackPlays the sound when you expand an image or hover a thumbnail.
Create sound imagesUploads your audio and renames your image with the [sound=] tag, ready to post.
Combined mp4 downloadsMerges an image or webm with its audio into one looping video file.
Thread searchLists active threads on any board whose opening post has a sound.
Themes and templatesRearrange the header, rows and footer, add custom CSS, and switch themes with a key.

Installation

The player is a userscript: a small script that a browser extension runs on the pages it's written for. Installing takes about a minute.

  1. Install a userscript manager

    Add one of these extensions to your browser. Any of them can run the player.

    • Violentmonkey: free and open source, for Chrome, Firefox and Edge.
    • Tampermonkey: for Chrome, Firefox, Edge, Safari and Opera.

    On Chrome, Edge and other Chromium browsers, the manager may also need permission to run user scripts. If it shows a notice, open the extension's Details page from chrome://extensions and turn on Allow User Scripts. On older browser versions, turn on Developer mode instead.

    Greasemonkey isn't recommended. It lacks the API the player uses to keep settings in sync between open tabs.

  2. Install the script

    Click the button below. Your userscript manager opens an install page listing the script's permissions. Confirm with Install.

    Install the stable build

    If the browser shows the script's source code instead, the manager isn't active. Check that it's enabled, then click the link again.

  3. Open a sounds thread

    Go to a thread with sound images, usually on /gif/ or /wsg/. With Autoshow on, which is the default, the player opens by itself once it finds the first sound. You can also open it with the Sounds link next to the board's Settings link.

Choosing a build

All builds come from the same source. They differ only in packaging and in which update channel they follow.

Stable

The normal, minified script. Recommended for almost everyone.

Install stable

Readable

The same release without minification, so you can read the code before you run it. It is the build published to Greasy Fork.

Install readable

Beta

Rebuilt on every change to master. Its version ends in the build number, for example {{VERSION}}.590.

Install beta
Keep only one build The builds share a script name, so most managers replace one with the other. Whichever you installed last decides which update channel you follow. If your manager lists two copies, disable one, or you'll get two players.

Supported sites

The script runs on 4chan and on these archives. Archived threads get the playlist and most features, but not inline playback. Some archives block the video encoder (see Archive support).

  • boards.4chan.org
  • boards.4channel.org
  • desuarchive.org
  • arch.b4k.co
  • arch.b4k.dev
  • archived.moe
  • archive.palanq.win
  • archive.nyafuu.org
  • warosu.org

The player works with 4chan's native extension, 4chan X and 4chan XT. Some extras, like the header controls, need 4chan X.

Other extensions

4chan External Sounds

If you also run 4chan External Sounds, both scripts will play audio when you expand an image. Turn off this player's inline playback under Settings › Playback › Inline Player: uncheck Expanded Image and Hover Image.

Updates and backups

Your userscript manager checks for new versions on its usual schedule, or when you ask it to check now. After an update the player shows a short notice with a link to the changelog. You can turn that notice off with Show Update Notifications.

Settings are stored by the userscript manager, not the website. They survive clearing cookies but are usually deleted if you uninstall the script. To keep a copy, use Export at the top of the settings view. Import the file later to restore everything.

Quick start

  1. Open a thread with sounds. The player appears with the first sound loaded. If it doesn't, click Sounds at the top of the page.
  2. Press play or click any playlist row. When a sound finishes, the next one starts.
  3. Move the player by dragging its header, and resize it by dragging any of its corners.
  4. Right-click a playlist row for its menu: jump to the post, read the track details, download, filter or remove it.
  5. Hide the player with the ✕ button or H. Hiding pauses playback, unless you turn off Pause On Hide.
  6. Open settings from the view menu (the ▾ button in the header) and pick Settings.
Tip Press / on this page to search. Searching "volume", "repeat" or "filters" jumps straight to that setting.

The player

The player is a floating window with a header, an image area, playback controls, a playlist and a footer. The header's view menu switches the window between four views: Player, Settings, Threads and Tools.

Opening the player

On native 4chan a [Sounds] link appears at the top and bottom of the page, next to Settings. With 4chan X it's an icon in the header bar. Click it again to hide the player. If those links are hidden (4chan's mobile view, or StyleChan with Show Navigation Links off), a small round play button appears in the bottom-left corner instead.

Buttons on posts

The player adds a button to each post that has a sound:

  • Play (a ▶ icon after the filename on 4chan, Play on FoolFuuka archives, [play] on warosu) plays that post's sound in the player.
  • Filter / Add appears when a post's sound was blocked by your filters or isn't on an allowed host, or when you removed it from the playlist. Hover over it to see why. Clicking it adds the sound to the playlist: for a filtered sound it adds the host to Allowed Hosts and removes the lines in Filters that blocked it. That's saved, so it applies to every post with that host, image or link. For a sound you removed, it just brings it back.

Image and controls

  • Image: shows the image or webm of the playing sound. Click it to open the full file in a new tab. In the playlist view, drag it up or down to change its height. The minimum is 125 px.
  • Previous / Next: skip tracks. Pressing Previous more than Restart After seconds into a track restarts the track instead.
  • Play / Pause
  • Seek bar: click or drag to jump. The lighter band shows how much has loaded.
  • Time / Duration
  • Volume: click the speaker to mute. Drag the bar to set the level.
  • Fullscreen: fills the screen with the image and keeps the controls.

When the player is too narrow for everything, controls are hidden in the order set by Hide Order.

Playlist

  • Click a row to play it.
  • Drag a row to change the play order.
  • Search with the box above the list. It matches the sound's name, post number and URL. The playing sound always stays visible. You can hide the box with the Toggle Playlist Search key.
  • Dead sounds are rows whose audio failed to load. Playback skips them and the footer counts them separately. Click a dead row to try loading it again.
  • Right-click a row, or click its ▾ button, to open its menu.

Footer

The default footer shows 3 / 42 sounds, the playing position and the total. Click it to scroll the playlist to the playing sound. If any sounds failed to load it adds (+ 2 dead). If you removed any sounds it adds (2 removed): click it to put them back. While a sound is selected it also shows:

  • Post link: jumps to the post.
  • Open [ image sound ]: opens either file in a new tab.
  • Download [ image sound video ]: the same downloads as in the row menu.

Drag any corner to resize the player. You can change the footer with the footer template.

Display modes

Image view

The playlist toggle in the header hides the list so the image fills the player.

Fixed playlist theme

The built-in Fixed Playlist theme pins the playlist to the right edge of the page at full height. Everything except the list is hidden; hover over the top to bring the header back. Drag the left edge of the header to change the width. Switch to it from the theme menu in the header, or under Settings › Theme.

Minimised

While the player is hidden and a sound is selected, playing or paused, a thumbnail of it can stay in the bottom-right corner of the page. Click it to bring the player back. With 4chan X you can also show playback controls in the 4chan X header.

Media keys and system controls

With Hardware Media Keys on, the keyboard's play, pause, next and previous keys control the player. Your operating system's media panel also shows the track title, artist and artwork.

Adding local files

To play images from your computer, click + in the header and choose them, or drag them onto the player. You can drop whole folders. The images need [sound=…] in their filenames, the same as in a thread. This is a good way to check a sound image works before you post it.

Combined video downloads

A sound is normally two files: the image or webm from the post, and the audio from the [sound=…] tag. A combined download merges them into one .mp4 that you can save or share anywhere.

  • The image is looped for the whole length of the audio. A short gif or webm repeats until the song ends.
  • The audio is never trimmed. A visual longer than the audio is cut to match it.
  • A still image is held on screen for the whole track.

There are three ways to make one:

  • The video button in the footer's download group, for the current sound.
  • Download › Video in a playlist row's menu, for any sound, without playing it.
  • Combine to mp4 in Tools › Download All, for the whole thread as a zip of mp4s.

Encoding speed

The first combined download fetches the ffmpeg encoder, about 31 MB. Your browser caches it after that. Encoding uses a single CPU core and runs on the page itself, so the tab freezes for a few seconds while it works. Browser and site restrictions cause this, not a setting:

  • No multithreading. Multi-threaded ffmpeg needs SharedArrayBuffer, which browsers only allow on cross-origin isolated pages. Only the website can turn that on, and a userscript can't change it.
  • No background worker. 4chan's content security policy blocks the worker the encoder would normally run in, so it has to run on the page.

To keep it quick, the player encodes one loop of the visual and copies it for the repeats. A long song over a short gif takes about as long as a short one.

If the freeze bothers you, turn on Fast Video Encoding. It's about twice as fast, but the files are about three times larger.

Archive support

Some archives' security settings stop the encoder from loading. desuarchive, for example, doesn't allow unsafe-eval. On those sites the video download buttons are hidden, and Combine to mp4 says it isn't available instead of failing halfway. Everything else works, and combined downloads still work on 4chan.

Sound filenames

A sound image is an ordinary image whose filename contains a sound tag pointing at an audio file:

My Song[sound=files.catbox.moe%2Fabc123.mp3].png
  • The text before the tag is the sound's name, shown in the playlist. With no name, the player uses the post number.
  • The URL is percent-encoded, because filenames can't contain /. Leave out https://.
  • One filename can have several tags, each with its own name: Intro[sound=…]Outro[sound=…].webm. They play one after the other.
  • The player only loads audio from hosts in Allowed Hosts.

Accepted variants

The player also reads these spellings, so older posts keep working:

FormExample
Brackets[sound=…], (sound=…) and {sound=…}
Separator=, :, |, $ or a space after sound
Keywordsound or audio, in any letter case
Catbox shorthand[catbox=abc123.mp3] means files.catbox.moe/abc123.mp3
Fatbox shorthand[fatbox=abc123.mp3] means files.fatbox.moe/abc123.mp3

Try it: build a filename

Rename your image to this, keeping its extension. The Create Sound Image tool does the same for you and uploads the audio as well.

Using settings

Open settings from the view menu ▾ in the player header. They're split into six tabs: Display, Playback, Filter, Keybinds, Theme and Hosts. Hover over the ⓘ icon next to a setting for a short description in the player.

When changes are saved Checkboxes and dropdowns save as soon as you change them. Text boxes and lists save when you click or tab out of the field. A change in one tab reaches your other open tabs right away.

Settings toolbar

The icons at the top left of the settings view:

How and when the player appears, how it fits on the page, and its colors.

Pause On Hide

CheckboxDefault: on

Pauses playback when you hide the player. Turn it off to keep music playing in the background while you browse. A thumbnail or the 4chan X controls still let you control it.

Show Update Notifications

CheckboxDefault: on

After an update, shows a short notice with the new version number and a link to the changelog.

Playlist Loading Bars

CheckboxDefault: on

Draws thin lines on the playing sound's playlist row as it downloads, behind the row's text: along the top edge for the video and along the bottom edge for the audio. Browsers stop downloading a long video a little way ahead of where it's playing, so its line can pause and carry on as it plays. The colors are Row Video Loading and Row Audio Loading.

CheckboxDefault: off

Allowed Hosts

List

Host fields

Default
Checkbox

Pre-selects this host in the Create tool. Only one host can be the default.

Remove
Link

Deletes the host. You can bring back a removed built-in host with Restore Defaults.

Name
TextRequired

A unique label, shown in the Create tool's host dropdown.

URL
TextRequired

The upload endpoint. The file is sent there with a POST request as multipart form data. If you leave out https:// it's added for you.

Response Path
TextOptional

For hosts that reply with JSON: the dotted path to the link or filename in the reply. For example, files.0.url reads response.files[0].url. When this is set the reply is read as JSON.

Response Match
RegexOptional

For hosts that reply with plain text or HTML: a regular expression, without the slashes. Its first capture group is the link or filename, so it needs one. For example, href="([^"]+\.mp3)". Ignored when Response Path is set. With neither set, the whole reply is used as the link, which suits catbox.

File URL Format
TextOptional

Use this when the host replies with only part of the link, such as a filename. %s is replaced with the reply. For example, a.pomf.cat/%s turns abc.mp3 into a.pomf.cat/abc.mp3.

Data (JSON)
JSONRequired

The form fields sent with the upload, as a JSON object. The value "$file" marks the field that carries the audio file, and one field must have it. Fields set to null aren't sent, so a host can list optional fields, like an account hash, for you to fill in.

{
    "reqtype": "fileupload",
    "fileToUpload": "$file",
    "userhash": null
}
Headers (JSON)
JSONOptional

Extra HTTP headers for the upload, as a JSON object. This is usually where an API token goes. Leave it empty if the host doesn't need any.

{
    "token": "your-api-token"
}

Themes and templates

The header, row, footer and 4chan X header are built from templates: plain text and HTML in which keywords are replaced with live content. You edit them under Settings › Theme. When the layout is how you want it, use Save Current to keep it as a theme you can switch to.

In every template except the row template, sound tokens refer to the sound that's currently selected, playing or paused. In the row template they refer to that row's sound.

Conditional blocks

BlockShows its contents…
p:{ … }…only when a sound is selected. In the row template, only on the row that's playing. When the condition is false the contents are left out completely.

Other scripts and bookmarklets can control the player by sending a PlayerEvent on the page's document. Put the action's name in action and its arguments, as an array, in arguments:

Troubleshooting

The Sounds link or the player doesn't appear

Check that your userscript manager is enabled and that the script is turned on for the site. The manager's toolbar icon usually shows a count of the scripts running on the page. Make sure you're on one of the supported sites. On 4chan X the link is an icon in the header bar, not a [Sounds] text link.

Some sounds in the thread are missing from the playlist

Look for a filter button on the post and hover over it to see the reason. Usually the audio is on a host that isn't in Allowed Hosts, or it matches one of your Filters. Clicking the button adds the sound, and saves the change: its host is added to Allowed Hosts and the filters that blocked it are removed. To change those lists by hand, edit them in the settings. The playlist updates as soon as you click out of the field.

If there's no button: the player only sees posts that are on the page. 4chan X's Show Last (reply pruning, on by default in stickies) keeps older replies off the page until you show them, and their sounds are added once you do. If you removed the sound yourself, the post has a restore button instead, and the footer shows how many you removed.

A row is marked dead or a sound won't play

The audio file couldn't be loaded. It may have been deleted from the host, or the host may be down or blocked on your network. Click the row to try again. If catbox links don't load for you, try the Fatbox Rerouter.

Two sounds play when I expand an image

Another script, usually 4chan External Sounds, is also playing it. Turn off Expanded Image and Hover Image in this player, or turn off inline playback in the other script.

Keyboard shortcuts don't do anything

By default shortcuts only work while the player is open, and never while you're typing in a text box. Set Enabled to Always to use them with the player hidden. Make sure 4chan X or another script isn't using the same key.

The page freezes when I download a video

That's expected. The encoder runs on the page and can't run in the background on 4chan, so the freeze is a browser limit. It lasts a few seconds. Fast Video Encoding shortens it.

The video download button is missing

On some archives, such as desuarchive, the site's security settings stop the encoder from loading, so the button is hidden. It's also hidden for webms that already have their own audio, since there's nothing to combine.

Create Sound Image says the filename is too long

The name, the encoded URLs and the tags have to fit in about 218 characters. Use a shorter name, fewer sounds per image, or a host with shorter links. catbox links are short.

I broke my layout with a template

Each template has a Reset link. Switching to the Default theme resets all the templates and the Custom CSS at once. As a last resort, the Reset icon at the top of settings puts everything back to its defaults.

Where do I report a bug or ask for a feature?

Open an issue on GitHub. Say which browser, userscript manager and site you're using, whether you run 4chan X, and what the browser console shows.
